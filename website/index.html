Tier Hierarchy

Framework packages support solid borders. For dashed, dotted, or gradient borders, use @cornerkit/core directly.

Installation

npm / yarn / pnpm:

npm install @cornerkit/core

CDN (unpkg):

<script src="https://unpkg.com/@cornerkit/core@1.3.0"></script>

CDN (jsDelivr):

<script src="https://cdn.jsdelivr.net/npm/@cornerkit/core@1.3.0"></script>

Vanilla JavaScript

import CornerKit from '@cornerkit/core';

// Create instance
const ck = new CornerKit();

// Apply to element
ck.apply('#my-element', {
  radius: 20,
  smoothing: 0.8
});

<div

</script>

ck.apply('#my-element', config);

Questions

Squircles, answered

What is a squircle?

A squircle is a shape between a square and a circle, drawn with a superellipse curve. Unlike a rounded rectangle, its curvature builds gradually from the straight edge instead of switching abruptly to a circular arc. Apple uses squircles across iOS for icons, buttons, and cards, which is why they read as smoother and more polished.

Why not just use CSS border-radius?

CSS border-radius draws a circular arc that meets the straight edge at a single point, creating a visible transition, especially at larger sizes. A squircle has continuous curvature, so the edge flows into the corner with no kink. cornerKit clips elements with a real superellipse path, the same profile iOS uses.

How do I match Figma's corner smoothing in CSS?

cornerKit's smoothing parameter maps to Figma's corner smoothing setting: smoothing 0.6 corresponds to roughly 60% corner smoothing in Figma, the iOS preset. Apply it with ck.apply(element, { radius: 20, smoothing: 0.6 }) and the rendered corner matches the design instead of falling back to plain border-radius.

Does CSS support squircles natively?

Partially. The CSS corner-shape: squircle property ships in Chrome 139 and newer Chromium browsers, but Firefox and Safari do not support it yet. cornerKit gives you squircle corners in about 98% of browsers today via SVG clip-path, with a graceful border-radius fallback everywhere else.

Does cornerKit work with React, Vue, or Svelte?

Yes. Official packages exist for all three: @cornerkit/react (component and hook), @cornerkit/vue (component, composable, and directive), and @cornerkit/svelte (component and action). All wrap the same zero-dependency @cornerkit/core library.

Will squircle corners slow my page down?

No. The core library is 5.9 KB gzipped with zero dependencies, renders in under 10 ms per element, and updates on resize through a debounced ResizeObserver. Off-screen elements can be deferred with lazy loading via IntersectionObserver.
